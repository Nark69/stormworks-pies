[h1]PIES — Paintable Indicator Editor for Stormworks[/h1]
[b]PIES[/b] (Paintable Indicator Editor) is a free, open-source pixel editor built specifically for Stormworks' paintable indicator signs — design your mosaics on a real 9-px-per-block canvas and export them as a ready-to-spawn vehicle XML.

[h2]Made for the game[/h2]
[list]
[*]Canvas is measured in [b]blocks (9×9 px each)[/b], up to 100 × 100 blocks
[*]Exports a vehicle XML you can paste into the workbench — including the [b]microcontroller block[/b], auto-placed and auto-wired to every sign with its logic links
[*]Supports both sign (indicator, with glow layer + logic slots) and sign_na output
[/list]

[h2]Full editing toolkit[/h2]
[list]
[*]Pencil, eraser, flood fill, eyedropper, line / rectangle / circle shapes, text with four bitmap fonts, select → cut/copy/paste
[*]Separate [b]Background and Glow layers[/b], additive "both" preview, hold Shift for a quick glow peek
[*]Move (wrap-around shift), 90° rotate, mirror left-right / top-bottom, undo/redo (500 steps), keyboard shortcuts for everything
[/list]

[h2]Import from the game[/h2]
[list]
[*]Load any vehicle XML containing sign/indicator blocks: positions, rotations, background and glow pixel data are reconstructed so the picture matches exactly what you see in-game
[*]Non-paintable blocks and empty spots become [b]locked tiles[/b] (red-tinted): they can't be painted by accident and are skipped on export, so your vehicle keeps its original shape. Unlock any tile with the Lock tool to paint there
[/list]

[h2]Convenience[/h2]
[list]
[*]Live XML preview, one-click copy, file download, PNG snapshot of the canvas
[*]Projects save/load as small JSON files (plus browser autosave)
[*]Glow brightness darkening option for better in-game contrast
[/list]

[h2]Getting started[/h2]
Download pies.html and open it in any browser — no install, no server, fully offline. Single file, MIT licensed.
